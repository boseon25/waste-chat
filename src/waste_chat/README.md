# 순환 거래 작업실

폐기물을 내보내는 업체와 받아 쓰는 업체가 만나 거래 조건을 맞추고, 거래에 필요한 서류까지 함께 준비하는 로컬 애플리케이션입니다.

1. **가입** — 모든 업체가 처음에 업체 기초 정보(유형, 상호·담당자, 사업장 위치, 발생 품목 또는 허가·처리 정보)를 입력합니다.
2. **거래 찾기** — 어떤 폐기물이 어떤 상태로 얼마나 있는지, 어떤 상대를 찾는지 대화하듯 적으면 조건에 맞는 업체를 오른쪽 지도와 목록으로 보여 줍니다.
3. **요청·승인** — 후보 업체에 거래 요청을 보내면 상대 업체의 요청함에 품목·물량·메모가 표시되고, 승인하면 두 업체의 거래방이 열립니다.
4. **거래방** — 왼쪽은 업체 간 채팅, 오른쪽은 우리 업체만 보는 AI 도우미입니다. 운반업체 등이 더 필요하면 ‘업체 초대’에서 요청을 보내고, 승인하면 같은 방에 들어옵니다.
5. **서류** — 모든 업체가 ‘거래 진행에 합의’를 누르면 업체별로 따로 준비할 서류와 함께 작성할 서류를 AI 안내가 채팅에 올립니다. 따로 준비하는 서류는 각자 체크하고, 함께 작성하는 서류는 ‘○○ 작성 중’, ‘v1 공유 · 확인 2/3’처럼 상태가 보입니다.
6. **서류 작성** — ‘작성하기’를 누르면 서류 작성 화면이 열리고 가입 때 입력한 업체 정보가 먼저 채워집니다. ‘채팅방에 공유’를 누르면 작성본 PDF가 거래방 채팅에 올라갑니다.
7. **다음 절차** — ‘절차’ 탭과 AI 도우미가 계약 → 행정 신고 → 반출·운반·인수 → 정산·사후관리 중 지금 단계와 남은 항목을 알려 줍니다.

## 실행

Python 3.10 이상이 필요합니다. 터미널에서 `app.py`가 있는 폴더로 이동해 실행합니다.

```bash
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python app.py
```

브라우저가 열리지 않으면 터미널에 표시된 127.0.0.1 주소를 엽니다. 종료는 Ctrl+C, 고정 포트는 `python app.py --port 8080`입니다.

### AI 키는 `.env`에 한 번만

`.env.example`을 `.env`로 복사하고 키를 넣습니다. 화면에서 키를 입력할 필요가 없습니다. `.env`는 `.gitignore`에 들어 있습니다.

```
TIMELYGPT_API_KEY=발급받은_키
# TIMELYGPT_MODEL=openai/gpt-4.1-mini
```

키가 없거나 Timely가 키를 거절하면 ‘기본 안내 모드’로 동작합니다. 이때는 품목·물량 표현을 규칙으로 읽어 업체를 찾고, 서류·절차 안내도 정해진 내용으로 답합니다.

### 혼자서 여러 업체 역할 시험하기

로그인 화면의 **예시 업체**(가상의 자료, 비밀번호 `demo1234`)로 바로 들어갈 수 있습니다. 왼쪽 아래 업체 이름 → **다른 업체로 전환**으로 상대 업체 화면을 확인하거나, 브라우저의 시크릿 창을 하나 더 열어 두 업체를 동시에 띄우세요.

### 다른 컴퓨터에서 접속하게 하기

```bash
python app.py --lan
```

같은 와이파이·사내망의 다른 컴퓨터가 터미널에 표시된 `http://내IP:8080` 주소로 접속할 수 있습니다. 모두 같은 서버에 가입하므로 서로 검색되고 요청을 주고받습니다. macOS가 “들어오는 연결을 허용할까요?”라고 물으면 허용하세요. 암호화(HTTPS) 없이 열리므로 시험할 때만 켜고, 실제 비밀번호나 실제 업체 자료는 넣지 마세요. 터널 주소를 쓸 때는 `--allow-host 주소`를 함께 줍니다.

### 어느 네트워크에서나 접속하게 하기

와이파이가 달라도, 멀리 있어도 접속하게 하려면 Cloudflare의 터널 프로그램으로 임시 공개 주소를 만듭니다. 한 번만 설치합니다 (Apple Silicon 맥 기준).

```bash
mkdir -p ../.tools && cd ../.tools
curl -L -o cf.tgz https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-darwin-arm64.tgz
tar xzf cf.tgz && rm cf.tgz && cd -
```

그다음부터는 이렇게 실행합니다.

```bash
python app.py --public
```

잠시 뒤 터미널에 `https://….trycloudflare.com` 주소가 나옵니다. 이 주소를 상대에게 보내면 됩니다. 서버를 끄면 주소도 사라지고, 다시 켜면 새 주소가 만들어집니다. 주소를 아는 사람은 누구나 접속할 수 있고 예시 업체 비밀번호는 공개된 값이므로, 실제 업체 자료는 넣지 마세요.

### 저장 위치와 범위

- 업체·요청·거래방·채팅·서류 상태는 `data/platform.db`(SQLite)에 저장됩니다. 폴더를 새로 풀어 덮어쓰면 함께 지워지므로, 유지하려면 `WASTE_DATA_DIR=/다른/폴더`로 위치를 바꾸세요.
- 기본으로는 이 컴퓨터(127.0.0.1)에서만 열립니다. 실제로 여러 회사가 상시 접속하려면 별도의 서버 배포와 HTTPS, 본인 확인 절차가 필요합니다.
- 후보 업체는 가입 업체가 등록한 품목과 거리로 고릅니다. 허가 범위와 적법성은 판단하지 않으며, 지도는 OpenStreetMap 타일을 사용해 인터넷 연결이 필요합니다.

## 화면 코드를 바꾼 뒤 다시 빌드하기

문서 탐색에는 Astryx 0.7.16의 `AppShell`, `SideNav`, `SideNavSection`, `SideNavItem`을 사용합니다. 왼쪽 목록에 실제 거래 서류를 업무 단계별로 묶었습니다. [참고한 공식 Side Nav 예제](https://github.com/meta/astryx/blob/v0.7.16/packages/cli/assets/templates/pages/shell-side-nav/page.tsx)

서류 작성 화면만 빌드가 필요합니다. Python 서버가 `web/ui/`에 들어 있는 빌드 파일을 브라우저로 전송합니다. 프론트엔드 소스를 수정할 때는 다음 명령을 실행한 뒤 브라우저를 새로 고칩니다. 이 빌드는 Node.js 24에서 확인했습니다.

```bash
cd frontend
npm ci
npm run build
```

일반 작성 화면의 진입점은 `frontend/src/main.jsx`, PDF에 문구를 직접 배치하는 화면은 `frontend/src/finish.jsx`, 공통 테마는 `frontend/src/theme.jsx`입니다. 배포할 때는 `web/ui/`도 함께 전달합니다.

## 한 건을 따라 작성하기

1. 첫 화면의 **폐기물 기초 정보 입력서**를 선택합니다. 키 없이 시험하려면 채팅에 `업체명 (상호)=다온자원`을 입력합니다. 다음 메시지에는 `발생 공정=사출 성형`을 입력합니다. 답변에 표시된 항목명을 누르면 해당 입력칸을 직접 수정할 수 있습니다.
2. 자연어를 쓰려면 **AI 연결 설정**에 본인이 새로 발급한 Timely 키를 한 번 입력합니다. 배출업체 상호와 발생공정을 한 문장으로 알려주면 여러 항목을 채울 수 있습니다. 기본 모델은 `openai/gpt-4.1-mini`입니다. 운영체제 환경변수 `TIMELYGPT_API_KEY`도 지원합니다. 키는 배포 파일에 포함되어 있지 않습니다. API는 입력 문장·현재 문서 항목명과 작업 지시를 받습니다. 완성 PDF나 사건 전체가 모델로 전송되지 않습니다.
3. **업무 경로**에서 예를 들어 ‘외부 위탁 검토’, ‘원료·제품 / 중간가공’, ‘일반 정기 배출 신고 대상’을 켜고 **어떤 서류가 필요해?**라고 입력합니다. 이 선택은 보여줄 서류를 정합니다. 실제 신고 대상 및 시설의 적법성은 담당자가 자료로 확인합니다.
4. **제6호 열어줘**, **건설 제7호 열어줘**, **처리업체용 제5호 열어줘**, **정산표 열어줘**처럼 입력하거나 왼쪽 서류 목록에서 선택합니다. 새 서류에서 배출업체 상호를 고르고, 기초 입력서의 상호가 맞으면 **이 값 반영**을 누르세요. 후보 업체를 알아보는 동안에는 허가번호·수탁 가능 여부·목적지·처리단가를 비워 두고 회신받은 뒤 작성하세요.
5. 문서의 **미리보기**에서 현재 작성본을 쪽별로 확인하고 **PDF 저장**으로 전체 문서를 내려받습니다. 4 MiB가 넘는 작성본은 위쪽의 새 탭 열기 또는 PDF 저장을 사용합니다. 항목이 연결된 서식에 문구를 더 넣을 때는 **나머지 칸 직접 배치**에서 내려받은 작성본 또는 원본을 열고 페이지에서 위치를 지정해 추가한 다음 별도 PDF로 저장할 수 있습니다. HWP로 마감할 때는 동봉한 HWP 원본을 한글에서 여세요.
6. **작업 파일 → 작업 저장 (.json)**으로 입력·대화·메모를 보관하고 다시 불러올 수 있습니다. JSON은 브라우저가 내려받습니다. 첨부 사진의 축소 사본이 JSON에 들어갑니다. 원본 사진·발급본·계량표는 별도로 보관합니다. 발급자료는 발급자와 확인내용을 메모하고, 행정 신고·올바로 입력·서명은 해당 권한자가 수행합니다. [건별 폴더 예시](cases/README.md)

### 기초정보 JSON에서 다른 서류로 이어받기

1. **작업 파일 → 기초정보 불러오기**에서 외부 기초정보 파일을 엽니다. 동봉된 [두 건의 테스트 JSON](cases/examples/part2-intake-sample.json)이나, JSON의 `true`·`false`·`null`에 Markdown 굵게 표시가 붙은 원래 예시 파일도 사용할 수 있습니다.
2. **기초정보 연결**을 누르기 전에 작업 대상 한 건을 선택합니다. 예시의 PE 필름과 세척액은 각각 별도의 배출 건입니다. 현재 작업을 보관하려면 작업 JSON을 먼저 저장하세요.
3. **반입·운반 견적문의서**를 열고 폐기물 이름이나 발생공정의 빈칸을 고릅니다. 후보의 값과 출처를 확인한 뒤 **이 값 반영**을 누르세요. 기초정보를 연결한 것만으로 PDF에 값이 들어가지는 않습니다.
4. 예를 들어 세척액의 이번 물량은 **100 L**, 2026년 8월 발생대장에는 **0.32 t**가 기록되어 있습니다. 제13호 첫 행의 ⑦ 발생량에는 **2026년 8월 · 320 kg/월**을 후보로 보여줍니다. 사용할 월과 해당 서류의 대상이 맞는지 확인한 뒤 반영하세요. 작업 JSON에 선택한 사례와 입력 출처를 보관하므로 나중에 다시 열어 이어서 작성할 수 있습니다.

두 사례 모두 `synthetic: true`인 개발용 자료입니다. 견적용 수량·월별 실적·이번 차량의 실제 계량량, 현장 호칭·법정 명칭은 서로 용도가 다릅니다. 예시에 없는 업체 등록번호와 실제 반출량은 별도 확인해서 입력합니다.

### 동봉된 빈 PDF에 직접 입력하기

동봉 원본 12종에서 **칸 선택**으로 작성할 수 있습니다. 제13호 폐기물분석결과서는 상단 정보, 6개 분석 행, 하단 제출일·제출인 정보 등 총 59칸을 지원합니다. **① 상호(명칭)** 칸 안을 누르고 채팅에 업체명을 보내세요. 이어서 **② 사업자등록번호** 칸을 바로 눌러 번호를 입력하세요. 분석표는 **작성할 칸** 목록에서 행과 항목을 함께 고를 수 있습니다. 분류번호는 여섯 자리를 한 번에 입력하면 인쇄된 하이픈 사이에 두 자리씩 들어갑니다.

다른 원본 11종에는 서식별로 주요 칸 97개가 연결돼 있습니다. 예를 들어 관리대장은 종류 칸이 연결돼 있습니다. 표시되지 않은 칸이나 여백에는 **자유 배치**로 문구를 넣을 수 있습니다. **작성 사본 PDF 저장**으로 작성본을 내려받고, 이후 편집하려면 **작업 파일**도 저장하세요. 이전 작업 파일의 수동 문구는 그대로 열립니다. 한 칸에 이전 문구가 하나만 있으면 그 칸을 선택해 값을 바꿀 수 있습니다. **원본 PDF 저장**은 빈 양식을 내려받습니다. 원본 미동봉 자료는 **자료 안내**에서 확인하세요.

**실제 제출 시 확인할 점 (2026년 11월 15일 확인)**

- 배출자가 신고하는 제6호는 상호·주소·배출 및 처리계획을 컴퓨터로 작성할 수 있습니다. 종이로 낼 때는 신고인의 서명 또는 인을 갖추고 해당 첨부서류를 준비합니다. 정부24는 이 민원에 인터넷·방문·우편을 안내하고 온라인 신청 경로로 올바로를 연결합니다. [제6호 서식](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110202&flSeq=160046499&gubun=) · [정부24 민원 안내](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=14800000193)
- 제13호의 제출인 기본정보는 미리 입력할 수 있습니다. 지정폐기물 처리계획 확인 대상인 배출자가 제출할 분석결과서는 폐기물분석전문기관이 작성해야 합니다. ⑪ 유해물질별 함유량은 해당 시험 결과를 따르고, 하단은 제출인의 서명 또는 인을 위한 칸입니다. [폐기물관리법 제17조제5항](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000450979) · [제13호 서식 및 작성방법](https://www.law.go.kr/LSW/flDownload.do?flSeq=170405579)

## 사진과 이전 입력을 활용해 한 칸씩 작성하기

- PDF의 **입력 칸 표시**를 켜고 원하는 칸을 누르거나 작성 대화의 **작성할 항목**에서 고릅니다. PDF에 아직 인쇄되지 않은 칸도 목록에서 고를 수 있습니다. 항목을 선택하면 `항목명=값`을 반복할 필요 없이 값만 보낼 수 있습니다. “칸을 누르면 값만 보내면 돼?”라고 물으면 화면 사용법을 안내합니다. “여기에는 무엇을 적나요?”라고 물으면 선택한 항목에 맞춰 답합니다.
- **무엇을 적나요?**로 선택한 칸의 설명과 준비할 자료를 확인합니다. **나중에 확인**을 누르면 값을 비워 둔 채 다음 항목으로 이동할 수 있습니다. 보류한 항목은 선택 목록에 표시됩니다.
- 다른 서류에서 같은 의미의 항목에 입력한 값은 출처와 함께 후보로 표시됩니다. **이 값 반영**을 누르면 현재 서류에 복사합니다. 복사한 뒤 원본 값을 바꿔도 이미 확인한 문서의 값은 유지됩니다. **이전 대화에서 문구 가져오기**에서는 이 작업에서 직접 보낸 메시지를 검색하고 원문 일부를 선택해 빈칸에 넣을 수 있습니다.
- **사진 첨부**에서 JPG, PNG, 정지 WebP를 고르거나, 채팅창에서 캡처를 붙여넣습니다. 작업당 최대 8장, 원본 한 장당 12 MiB입니다. 선택한 칸에 연결하고 사진을 보면서 값을 입력한 뒤 **입력값 반영**을 누릅니다. 사진을 다른 칸으로 다시 연결하거나 삭제할 수 있습니다. OCR은 제공하지 않습니다.
- 작업 JSON에는 문서별 입력값과 출처, 보류 및 후보 제외 상태, 대화, 메모, 원본에 추가한 문구와 위치, 첨부 사진의 축소 사본이 저장됩니다. 사진은 PDF에 합쳐지거나 채팅 모델로 전송되지 않습니다. 버전 1 작업 파일을 열면 당시 열려 있던 문서와 원래 쓰일 문서가 한 곳뿐인 항목을 복원합니다. 원래 문서를 구분할 수 없는 공통값은 **이전 작업 파일** 출처의 후보로 남습니다.

## 업체명을 입력했을 때의 코드 흐름

```text
web/workspace.js → POST /api/chat → app.py → conversation.update()
```

자연어라면 `timely.extract()`가 문장에서 키와 값을 제안합니다. 예를 들어 `{"generator_name": "다온자원"}`입니다. 서버는 현재 문서에서 사용할 수 있는 필드이고 값이 원문에 실제로 있는지 확인한 뒤 `updates`로 돌려줍니다. 브라우저는 이를 같은 작업의 `generator_name`에 넣고, 해당 문서의 입력값으로 `POST /api/pdf`를 호출합니다. `pdf_writer.render_document()`가 반환하는 PDF가 미리보기와 다운로드에 함께 쓰입니다.

공유하는 값의 의미는 동일해야 합니다. 배출업체 상호는 출처를 확인해 제5호·제6호에 복사할 수 있지만, 담당자 연락처와 사업장 전화, 현장 통칭과 법정 분류명, 연간 배출량과 특정 업체에 맡길 연간 물량 및 이번 실계량값은 서로 다른 키입니다. 자동 분류·수탁자 허가 조회·법적 적합성 확정과 시스템 제출 기능은 등록된 기능 범위 밖입니다.

## 서식 하나를 추가하는 순서

1. 원본 PDF와 편집용 HWP를 `templates/official/`의 관련 폴더에 저장하고 `SOURCES.md`에 법령명, 별지, 개정일, 출처를 적습니다.
2. `catalog.py`에 자료 성격, 단계, 책임 주체와 경로 조건을 추가합니다. 발급자료는 빈 양식으로 증빙을 대신 생성하지 않도록 `fields=[]`로 둡니다.
3. 채팅 자동 배치가 필요하면 `extra_pdf.py`의 사양과 지원 ID를 추가하고 `pdf_writer.py`의 렌더러 분기에 연결합니다. 여백, 인쇄 라벨, 원본 버전이 바뀌면 좌표도 검증하세요.
4. 한글·숫자·긴 문구를 실제로 넣고 내려받아 원본의 페이지 수와 입력 위치를 확인합니다. 한 칸의 값이 들어가지 않으면 문구를 줄이거나 직접 배치·편집용 원본을 사용합니다.

## 설치와 양식 점검

터미널에서 `python tools/check.py`를 실행하면 실제 키 없이 서식 원본, PDF 출력, 문서 선택과 공유값 구분을 확인합니다.
