# 법정 서식 원본과 출처

확인일: **2026-11-08**. 아래 17종은 국가법령정보센터가 현행 시행규칙의 별지로 제공한 원본입니다. 같은 이름의 HWP는 한글 문서, PDF는 대조·인쇄용입니다. 일반, 지정, 건설, 평가 폴더에 두 형식을 함께 수록했습니다. 모든 PDF의 서식 번호·페이지 수와 모든 HWP의 파일 형식을 확인했습니다.

- [폐기물관리법 시행규칙 · 현행](https://www.law.go.kr/법령/폐기물관리법시행규칙) / [확인 당시 시행본](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290881): 2026.10.2. 시행, 기후에너지환경부령 제60호.
- [건설폐기물의 재활용촉진에 관한 법률 시행규칙 · 현행](https://www.law.go.kr/법령/건설폐기물의재활용촉진에관한법률시행규칙) / [확인 당시 시행본](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=287419): 2026.6.22. 시행, 기후에너지환경부령 제42호.

직접 다운로드가 열리지 않으면 각 행의 ‘서식 상세’를 이용하거나 위 현행 시행규칙에서 **별표·서식 → 해당 별지 번호**를 선택하세요. 아래 개정·신설일은 서식 자체에 인쇄된 날짜로, 시행규칙 전체의 시행일과 다를 수 있습니다. 서식이 개정되면 새 원본을 사용하세요.
