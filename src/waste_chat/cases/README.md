# 진행 중인 건의 보관 위치

이 폴더는 배출업체 담당자가 쓰는 로컬 보관 공간입니다. 브라우저에서 내려받은 작업 JSON과 PDF를 해당 건의 폴더로 이동하세요. 프로젝트에서는 파일명을 바탕으로 법적 자격이나 접수 여부를 판정하지 않습니다.

예를 들어 한 배출 건을 아래처럼 정리할 수 있습니다.

| 예시 경로 | 넣을 내용 |
|---|---|
| 다온자원_사출자투리/작업.json | 작업 화면에서 내보낸 항목, 대화, 선택 조건, 자료 메모 |
| 다온자원_사출자투리/01_원자료/ | 기초 입력서, 발생공정 설명, 실물 사진, 기존 신고증명서 |
| 다온자원_사출자투리/02_업체회신/ | 회사별 허가증·보증 증빙·확인서·견적·반입기준 |
| 다온자원_사출자투리/03_계약과신고/ | 당사자 서명본, 관할청 접수·확인증명서 |
| 다온자원_사출자투리/04_반출건별/ | 인계번호별 계량표, 인수·처리 증빙, 정산·청구 자료 |
| 다온자원_사출자투리/05_사후관리/ | 해당 장부, 정기 처리 확인 기록, 실적보고 사본 |

운반업체나 처리시설이 다른 복수 계약은 작업 사본을 나누세요. 다음 차량 건을 시작할 때 이전 차량의 실계량값과 인계번호를 다시 사용하지 않도록 새 작업을 사용하세요. JSON과 PDF에는 실제 입력한 개인정보나 거래조건이 들어갈 수 있습니다.
