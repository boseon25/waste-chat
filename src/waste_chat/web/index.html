AI 연결 설정

API 키는 프로젝트 폴더의 .env 파일(TIMELYGPT_API_KEY)에 한 번만 넣으면 됩니다. 자연어 해석을 사용할 때 메시지와 현재 서식의 항목명이 로컬 서버를 거쳐 Timely AI에 전송됩니다. 원본 PDF와 작업 전체는 보내지 않습니다. 직접 입력과 PDF 보기는 키 없이 사용할 수 있습니다.

업무 경로 선택

해당하는 경로를 모두 선택하세요. 선택한 경로에 속한 문서가 함께 표시됩니다. 선택하지 않으면 모든 문서를 볼 수 있습니다.

경로 선택은 문서 탐색용입니다. 실제 적용 여부와 요구 서류는 별도로 확인하세요.

작업 파일

창을 닫기 전에 작업을 JSON 파일로 저장하세요. 이 파일에는 연결한 기초정보 한 건, 서류별 입력값과 출처, 대화, 첨부 사진 사본, 파일·접수 메모가 들어갑니다. API 키는 포함되지 않습니다.

파일·접수 메모

메모는 작업 JSON에만 담깁니다. 사진은 작성 대화의 사진 첨부에서 추가할 수 있습니다.
