## 5. 접수부터 회신·성적서 수령까지

1. 국립환경과학원 분석기관지정 → 검사기관에서 폐기물분석 전문기관 선택; 기관·지점·지정분야 확인

2. 선택 기관에 필요한 항목만 제시; 시험 가능 여부, 법적 목적에 맞는 방법·시료 조건·비용·기간·한 성적서 발급 여부 상담

3. 온라인 경로 정상 여부 재확인. 점검 중이면 공식 방문/택배 절차로 협의 (임의 이메일/주소 생성 금지)

4. 기관의 신청서·동의서에 검토한 정보를 옮겨 작성; 서명·개인정보 동의는 사용자 직접 수행

5. 수용 가능한 시료와 발송 지점을 기관에 확인한 뒤 제출/발송; 접수번호 보관

6. 기관이 작성·안내한 의뢰시험신청서와 수수료 확인 → 사용자가 결제 → 시험 진행

7. 시험 완료 통지 후 성적서 수령 방식(직접/택배/요청한 이메일 등) 확인하여 수령

8. 성적서를 같은 건에 첨부; 시료번호·채취일·시험일·단위·시험법·건조/습윤 기준을 대조; 빠진 항목만 보완
