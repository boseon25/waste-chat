## 5. 접수부터 회신·성적서 수령까지

1. 현장 관할·문의 목적 확인; 소관이 불분명하면 상담으로 문의

2. 공식 민원신청 입구에서 로그인/본인인증 (사용자 직접 수행)

3. 성명·주소·연락처·통지방식·제목·내용 작성; 생성한 초안은 검토 후 옮기기

4. 유사사례 검토 → 처리기관 선택 → 관련 자료 첨부 → 사용자가 제출

5. 접수번호 기록; 소관기관의 담당부서 배정 및 보완 요청 대응

6. 선택한 통지방식으로 처리결과 수령; 회신 원문을 같은 폐기물 건에 첨부

7. 회신의 현장·품목·조건·날짜와 필요한 값들을 대조; 없는 값만 추가 문의
