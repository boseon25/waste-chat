## 1. 공통 규칙

| 규칙 | 내용 | 이유 |
|---|---|---|
| **업체_키** | 법인 표기((주)·주식회사·㈜·(유)·유한회사·(합)·(사)·(재)·농업회사법인·영농조합법인) + 공백·가운뎃점 + 끝 괄호(지점명) 제거한 이름 **+ `|` + 시군구** | 파일마다 표기가 달라도 같은 업체로 묶기 ("(주) 승지" = "(주)승지", 회귀 S23) |
| 시도·시군구 | 주소 앞 단어에서 추출, "수원시 영통구"처럼 시+구는 합침. 주소에 없으면 원본의 시도·시군구 칸 사용 | 같은 이름 다른 회사 구분 |
| 분류번호 | 모든 업체 데이터는 별표 4 분류번호(6자리)에 연결. 원본이 4자리·2자리면 crosswalk로 말단 목록 | 법령 표와 같은 키로 판정 |
| 출처 | 모든 행에 `파일#시트#행` | 의심 값을 원본에서 바로 찾기 |
| 기준연도 | 파일 이름·자료 연도 | 오래된 자료 판단 |
| 개인정보 | 대표자 이름은 결과에 넣지 않음 (전화번호는 연락용으로 유지) | 판정에 불필요 |
| 원본 보존 | 원본 값은 `…_원문` 칸에 그대로, 해석 값은 별도 칸 | 해석이 틀려도 되돌릴 수 있게 |

### 정제 단계
1. 시트마다 `폐기물종류 | 폐기물코드 | 업체명` 머리글 줄을 찾고 그 아래부터 읽음 (업체명 빈 줄 제외)
2. **처리방법 칸 펼치기** — 한 칸에 여러 개
   `(2005)농업생산활동에 사용(재)(위탁), (2006)토질개선에 사용(재)(위탁)`
   → 정규식 `\((\d{4})\)\s*([^()]*?)\s*(?:\(재\)\s*)?\((자가|위탁)\)` 로 하나씩 → 처리방법 1개 = 1행
   (R-11 재활용환경성평가 문구는 "(재)"가 없어 선택 처리)
3. 처리방법코드 → `treatment_code_map`에서 **r_code**(R-1~R-11, 상위 수준)
4. **위탁가능**: 위탁=Y, 자가=N → **자가처리만 하는 업체는 상대 후보에서 제외** (회귀 S44)
5. 처리방법 칸이 비면 `상태=처리방법 없음`, 위탁가능 N
6. **중복 합치기**: (업체_키, 폐기물_구분, 폐기물코드, 처리방법코드, 주소)가 같은 220행 → 1행, 재생제품·출처는 이어 붙임
7. **crosswalk**: 폐기물코드 `5103` → `51-03`(중분류) → 별표 4 말단 목록 / 지정 일부 `06` → `06`(대분류)

1. **파일 종류 = 엑셀 제목 줄로 판별** (파일 이름 무관). 모르는 제목은 건너뛰고 보고서에 표시

   - 병합된 윗칸 이름을 오른쪽으로 채우고 아랫칸을 붙임 → `영업대상폐기물/생활`, `중간처분시설(소각제외)처리능력(톤/일)/기계적/증발농축`
   - 칸 이름 공백 제거
3. **합계·소계 줄 제거** (`…개소`, `합계`, `소계`). 소계 줄의 시도 → 아래 업체 줄에 채움
4. 같은 업체의 다음 공구·시설 줄은 시군구가 비어 있음 → 바로 윗줄 값 이어받기

### 정제 단계
1. `시설명` 머리글 줄 찾기 → 업체_키 (도로명주소 없으면 지번주소)
2. 처리폐기물정보 `51-01-00+51-02-00` → `;` 구분 **6자리 분류번호**
3. **facility_master** 만들기
   - 묶는 대상: partners_recycling(위탁가능 Y) + partners_disposal(영업중 Y) + partners_transport(영업중 Y)
   - 업체_키로 합쳐 `역할`을 모음: `재활용(허가)`, `처분(소각·지정)`, `운반(생활·사업장일반)` …
   - 좌표 연결 순서: ① 업체_키 일치 → ② 정규화 이름이 표준데이터에 하나뿐이면 연결 → ③ 없으면 `좌표_연결=없음(시군구 중심점 사용)`
