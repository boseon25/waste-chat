# law_agent 질문 체크리스트 v0

**총 10개 분야, 30개 확인 항목**

## A. 폐기물 분류

- [ ] **A-1.** 파트 1이 준 분류번호가 시행규칙 별표 4에 있는 번호이고, 폐기물 이름·성상과 맞는가?
- [ ] **A-2.** 이 폐기물은 지정폐기물인가? (예 / 아니오 / 분석해야 앎)
- [ ] **A-3.** 지정폐기물 여부를 위탁 전에 분석·확인해야 하는 대상인가? 대상이면 무엇을 언제 확인하는가?
  - 적용 조건: A-2가 '예'가 아닌 경우
- [ ] **A-4.** 여러 폐기물이 섞여 있는가? 섞였다면 분리할 수 있는가, 섞인 채로 어떤 분류번호로 보는가?

## B. 재활용 금지·제한

- [ ] **B-1.** 이 폐기물은 재활용이 금지된 폐기물인가? (법 제13조의2 제2항 각 호)
- [ ] **B-2.** 재활용이 제한되는 폐기물인가? 제한이면 허용되는 재활용 유형은 무엇인가? (시행령 별표 4의3 각 호)

## C. 순환자원 지정 여부 — 관문 1

- [ ] **C-1.** 이 폐기물이 순환자원 지정 고시의 품목인가? 품목 한정(예: IC 트레이만, 알루미늄·구리만, 도정 공장 발생분만)에 맞는가?
- [ ] **C-2.** 고시가 정한 용도(허용 R코드)와 방법 기준(이물질, 혼합 금지, 보관 방법)은 무엇이고, 사례가 맞는가?
  - 적용 조건: C-1이 '예' 또는 '조건부'인 경우

## D. 재활용 가능 여부 — 관문 2

- [ ] **D-1.** 이 분류번호에 허용된 재활용 유형(R코드)은 무엇이고, 각각 사전 분석이 필요한가?
  - 적용 조건: B-1이 '예'가 아닌 경우
- [ ] **D-2.** 허용 R코드 중 사례의 형태(원형 보존, 파쇄, 분말, 액상)로 실제 할 수 있는 것은? (재사용 R-1·R-2 등)
  - 적용 조건: D-1에 허용 유형이 있는 경우
- [ ] **D-3.** 이 재활용 유형에 적용되는 재활용 기준은 무엇인가?
  - 적용 조건: D-1에 허용 유형이 있는 경우
- [ ] **D-4.** 재활용 업체가 지켜야 할 준수사항은 무엇인가?
  - 적용 조건: D-1에 허용 유형이 있는 경우
- [ ] **D-5.** 지정폐기물을 재활용하면 어떤 허가를 가진 업체에만 맡길 수 있는가?
  - 적용 조건: 지정폐기물이고 D-1에 허용 유형이 있는 경우

## E. 에너지 회수

- [ ] **E-1.** 에너지 회수(R-9 계열)로 인정되는 기준(저위발열량, 회수효율, 외부 공급 등)은 무엇이고, 사례 값이 충족하는가?
  - 적용 조건: D-1에 R-9가 있는 경우

## F. 폐기물 처분 — 관문 4

- [ ] **F-1.** 이 분류번호에 허용된 처분 방법(소각·매립·중간처분)과 처리방법 코드는 무엇인가?
- [ ] **F-2.** 그 처분 방법을 쓸 때 지켜야 할 조건·수치 기준은? (소각 곤란 시에만 매립, 파쇄 크기, 수분 함량, 잔재물 처리 등)
  - 적용 조건: F-1에 허용 방법이 있는 경우

## G. 위탁 및 서류

- [ ] **G-1.** 처리를 위탁할 때 지켜야 할 기준·절차는? (적법 수탁자 확인, 수탁처리능력 확인서, 서면 계약, 보관 기간)
- [ ] **G-2.** 전자정보처리프로그램(올바로)으로 인계·인수 내용을 입력해야 하는가? 제외 대상인가? 입력 기한은?
- [ ] **G-3.** 운반 업체가 지켜야 할 운반 기준은?
- [ ] **G-4.** 순환자원으로 판매하면 인계서·수탁처리능력 확인 대상에서 빠지는가? 어떤 조건에서인가?
  - 적용 조건: C-1이 '예' 또는 '조건부'인 경우

## H. 신고 및 처리계획

- [ ] **H-1.** 이 배출 사업장은 사업장폐기물배출자 신고 대상인가?
- [ ] **H-2.** 지정폐기물 처리계획 확인 대상인가? (품목별 월 평균 배출량 기준과 사례 물량 비교)
  - 적용 조건: 지정폐기물인 경우
- [ ] **H-3.** 처리계획 확인 대상이면 제출 서류, 제출처, 기한은?

- [ ] **I-2.** 폐기물처리 신고 업체가 이 폐기물·재활용 유형을 받을 수 있는 범위인가? 신고자 준수사항은?
