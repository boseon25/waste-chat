1. 사용자용 (배출업체 담당자) — ./waste.sh
---------------------------------------------------------------------
./waste.sh new 입력서.docx                      # ① 입력서 접수 → 폐기물 목록 (1번을 작업 중으로)
./waste.sh new 입력서.docx --synthetic          #    가상 입력서로 연습할 때만 --synthetic
./waste.sh cases                                # 폐기물 목록 (▶ = 작업 중)
./waste.sh use 2                                # 작업할 폐기물 바꾸기 (번호 또는 case_id)

./waste.sh next                                 # ② 파트 1이 더 묻는 질문 (한 번에 최대 3개, 번호 붙음)
./waste.sh answer 1 "2026-11-09"                # 질문 번호로 답하기 (판 번호 자동)
./waste.sh next                                 # "더 물을 질문이 없습니다" 나올 때까지
./waste.sh code 51-03-01 "시행규칙 별표 4 폐합성수지류"   # 분류번호를 근거와 함께 기록
                                                #  * 입력서에 "분류번호 (가상)" 칸이 있으면 new 할 때 자동 기록 → code 생략 가능

./waste.sh send                                 # ③ 파트 2 판단 → 결과 바로 표시
./waste.sh send -v                              #    진행 과정을 쉬운 말로 보면서
./waste.sh send --queue                         #    감시(start)를 켜 둔 경우: inbox 에만 넣기
./waste.sh result                               # ④ 결과 다시 보기
                                                #    경로 · 가공업체 순위 · 운송업체 순위 · 필요한 서류 · 더 알려줄 것

  연습 순서 (가상 입력서):

  ./waste.sh next
  ./waste.sh answer 1 "2026-11-09"

  ④ 검토 요청 (진행 과정이 쉬운 말로 3초마다)  ⑤ 결과: 처리 방법·가공업체 순위·운송업체 순위·서류·더 알려줄 것
