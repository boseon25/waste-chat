3. 설치·실행 — 윈도우 (cmd 또는 PowerShell)
---------------------------------------------------------------------
  준비: 파이썬 3.10 이상 (설치할 때 "Add python.exe to PATH" 체크)

  (zip 풀기)
  cd C:\…\waste_agent
  py -3 src\law_agent\launch.py setup      # 가상환경 + 패키지 + waste.bat · waste.env 생성
  py -3 src\law_agent\launch.py doctor     # "문제 없음." 확인
  waste-admin.bat test                     # 431 passed
  waste-admin.bat web                      # 브라우저 http://127.0.0.1:8765/

  * PowerShell 은 앞에 .\ 를 붙인다:  .\waste-admin.bat web
  * 한글 깨짐 방지: 항상 waste.bat / waste-admin.bat / launch.py 로 실행 (python -m … 직접 실행 X)
  * 방화벽 창: 내 PC 에서만 쓰면 취소해도 됨
  * 윈도우는 아직 실제 PC 에서 처음 돌리는 것. doctor 결과를 공유해 주세요.

4. 사용 순서 (화면)
---------------------------------------------------------------------
  1) http://127.0.0.1:8765/  → 입력서(docx) 올리기
     분류번호 칸이 있는 입력서(intake_filled_example_분류번호.docx)면 분류번호 자동 기록
  2) 폐기물 고르기 → 파트 1 질문 답하기 → "검토 요청"
  3) 결과: 경로 · 가공업체 순위 · 운송업체 순위 · 필요한 서류
     거리 칸: "도로 23.4km · 31분 · 통행료 0원 (카카오)" 또는 "약 18.2km (직선 × 1.3 추정)"
  관리자 화면: http://127.0.0.1:8765/admin  (판단 과정·근거 원문·모델 답 전체)

  시연은 PE 필름(51-03-01)으로. 세척액(지정·액상)은 중간재활용업 범위 밖이라 보류가 정상.

6. 오류가 나면
---------------------------------------------------------------------
  doctor 에 "없음"                           → 그 줄 경로가 실제 폴더와 맞는지 (1번 파일)
  "환경변수 WASTE_LAW_DIR 가 비어 있음"        → env.sh / waste.env 가 waste_agent 바로 아래 있는지
  "WASTE_DATA_DIR … 지정하세요"               → 업체 표 경로
  "파트 1 스크립트가 없습니다"                  → src/part1 폴더가 있는지
  No module named 'langgraph' 등               → setup 다시 실행
  모델 호출 실패 (429)                          → 여럿이 같은 키로 동시에 돌림. 잠시 후 다시 / 한 사람만
  키 없이 화면 흐름만 볼 때                      → 리눅스: WASTE_DRY=1 ./waste-admin.sh web
                                                윈도우: set WASTE_DRY=1  후  waste-admin.bat web
